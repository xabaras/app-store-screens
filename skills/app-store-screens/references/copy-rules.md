# Copy and truthfulness

These rules win over any creative idea.

1. Every claim comes from the app's website, store listing, or app strings. Write the source next to each claim in `DESIGN.md`.
2. No invented ratings, reviews, download counts, percentages, money saved, or "#1" claims.
3. No invented testimonials, quotes, user names, or faces.
4. No feature the app does not have. Product area shows only screens (or brand art) the user provided.
5. AI features: help framing ("helps you…"), never guaranteed or always right.
6. Respect listing labels (e.g. if Play says "Contains ads", never claim "no ads").
7. Missing asset → clearly labelled placeholder and tell the user. Never fake a screen.
8. No invented lifestyle/stock photos. Full-bleed photo slides only with a file the user provided
   (and only when they asked for that style).

## Headline craft

- One idea per slide. Short: prefer ≤ ~6 words for the main claim when the language allows.
- Subline optional; never compete with the headline.
- Language of the run = language the user chose (can differ from storefront country).
  If they have not chosen one yet: **ask and stop** until they answer. Never guess from
  storefront, screens, or a silent `en` default.
