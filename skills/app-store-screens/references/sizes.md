# Store screenshot sizes (v1)

Export only these portrait sizes. Exact pixels; no “close enough”.

| Target | Size (W×H) | Notes |
|--------|------------|--------|
| iPhone (App Store 6.7″ / 6.9″ class) | **1290 × 2796** | Primary upload; Apple scales down for smaller phones |
| Play phone | **1080 × 1920** | 9:16; short side ≥ 320, long ≤ 3840 |

## Format rules

- PNG or JPEG; this skill exports **PNG**.
- **No alpha channel** (flatten onto an opaque background before export).
- App Store: 1–10 screenshots per localization.
- Play: 2–8 phone screenshots per listing.

## Out of scope for v1

iPad, Play tablets, feature graphic (1024×500), multi-size matrices.
